# Jutta: fertige Dateien

Hier liegen ausschließlich die **fertigen Installer** von Jutta, der
Diktier-App der Schurig GmbH. Kein Quellcode: der liegt in einem privaten Repo.

## Herunterladen

Unter **Releases** die neueste Fassung öffnen und eine der beiden Dateien
laden:

| Datei | wofür |
|---|---|
| `Jutta-Setup-<version>.exe` | der normale Weg, installiert Jutta |
| `Jutta-<version>-portable.exe` | wenn nichts installiert werden darf |

Windows zeigt beim ersten Start eine blaue Warnung („Der Computer wurde durch
Windows geschützt"). Das ist normal: Das Programm hat kein kostenpflichtiges
Zertifikat, und das soll auch so bleiben, damit Jutta nichts kostet. Auf
**Weitere Informationen** klicken, dann auf **Trotzdem ausführen**.

## Was Jutta macht

Taste drücken, sprechen, und der Text erscheint dort, wo der Cursor steht. Die
Spracherkennung läuft auf dem eigenen Rechner, nichts wird ins Internet
geschickt. Kein Konto, kein Abo.

Die vollständige Anleitung liegt jedem Release als `Bitte zuerst lesen.txt`
bei.

## Warum es dieses Repo gibt

Die Installer lagen bisher nur in einem OneDrive-Ordner, der nicht bei allen
synchronisiert wird. Wer ihn nicht hatte, kam an keine neue Fassung: Am
23.09.2026 lief bei einem Kollegen noch 1.2.3, während 1.5.2 aktuell war, und
er hat es nur zufällig bemerkt.

Dieses Repo ist der Ort, an den jeder ohne Konto und ohne Anmeldung kommt. Es
ist zugleich die Quelle, aus der Jutta sich selbst aktualisiert.
